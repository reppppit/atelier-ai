✧ 그림 만들기

참고 이미지는 현재 기기의 브라우저에서 미리보기만 해. 아직 AI 모델로 전송되지 않아.

✧ 생성 프롬프트

위에 설명을 적고 프롬프트 만들기를 눌러 줘.

이 첫 버전은 화면과 설정을 갖춘 프로토타입이야. 실제 그림 생성은 안전하게 연결할 AI 실행 서버를 정한 뒤 추가할 거야.

✧ AI 그림 생성

프롬프트를 실제 이미지로 만들어 줘.

생성 버튼을 누르면 무료 AI Horde에 요청해.

생성된 그림이 여기에 표시돼.
중요: 이 버전은 아직 AI 이미지를 직접 생성하지 않아. 실제 생성 기능을 연결하기 전에는 생성 완료라고 표시하지 않아.
